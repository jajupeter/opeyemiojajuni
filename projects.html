InsightBot: AI-Powered Research Tool

Problem Statement

Researchers, analysts, and students face information overload when processing multiple online articles or reports. Traditional reading and summarization methods are time-consuming and prone to cognitive fatigue, making it difficult to synthesize key insights across sources.

Solution

InsightBot automates research synthesis by fetching, parsing, and embedding online articles into AI-readable vectors. Users can query the aggregated knowledge base and instantly receive concise, citation-supported answers. The app bridges human curiosity and machine reasoning, transforming raw data into structured insight.

Pipeline

Built with Streamlit and LangChain, the system integrates the following components:

  • WebBaseLoader – Extracts and cleans text from provided URLs.
  • RecursiveCharacterTextSplitter – Segments long documents into manageable chunks.
  • OpenAIEmbeddings – Converts text chunks into high-dimensional numerical vectors.
  • FAISS – Stores embeddings locally for efficient semantic retrieval.
  • RetrievalQAWithSourcesChain – Uses OpenAI’s LLM to answer queries with contextual citations.

Deployment

The application is deployed on Streamlit Cloud with secure API key handling via python-dotenv. It features a dark-mode user interface and interactive sidebar for multi-URL input and querying.

Results

InsightBot efficiently extracts insights from up to three online articles within seconds, providing verifiable and concise answers supported by direct source links. It demonstrates an end-to-end LLM retrieval-augmented generation (RAG) workflow in a user-friendly research environment.

House Price Prediction App

Problem Statement

Accurately pricing residential properties is one of the most critical steps in real estate. Traditional valuation methods rely heavily on manual appraisals or simplistic statistical models, which are often time-consuming, subjective, and unable to capture complex non-linear relationships in housing features.

Solution

TThe House Price Prediction App is an AI-powered interactive tool built with Streamlit. Using a trained Deep Learning regression model on the King County Housing Dataset (2014–2015), it estimates house prices based on 18 key features such as square footage, number of bedrooms/bathrooms, year built, renovation status, and geolocation. The app provides a simple and user-friendly web interface for real-estate stakeholders, buyers, and sellers to obtain instant, data-driven price predictions.

🔄 MLOps Pipeline

  • Data Collection & Preprocessing: Cleaned dataset, removed non-essential fields (id, date, view), and normalized features using MinMaxScaler.
  • Modeling: Built and trained an Artificial Neural Network (ANN) with TensorFlow/Keras, optimized for regression tasks.
  • Deployment: Packaged into a Streamlit app and deployed on Streamlit Cloud for real-time access.
  • Version Control: Managed with GitHub for collaboration and reproducibility.

📊 Results

The app successfully demonstrates the use of deep learning in real-estate valuation. Users can interactively test scenarios by adjusting property features, instantly receiving predicted prices. The model delivers robust predictions, and the streamlined interface improves accessibility for non-technical users.

Overall, the app highlights how AI can enable faster, more objective, and scalable property valuation compared to traditional methods.

Immersive Crisis Leader Emergency Response Training (ICLERT)

ICLERT closes the gap left by traditional drills with AI‑driven VR that captures the chaos of real incidents. Leaders practice split‑second judgment in lifelike scenarios to measurably improve readiness.

We engineered a LiDAR/GIS digital twin of campus (shelter + EOC), then built a modular curriculum—10 crisis courses + 2 hazard scenarios (gas leaks, electrical failures)—for Meta Quest 3 and CAVE.

35+ leaders trained; 10+ modules deployed. In partnership with the Louisiana Department of Health, the program scales statewide to strengthen workforce resilience and compliance.
